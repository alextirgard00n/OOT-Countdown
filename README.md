# OoT Countdown

A countdown to the release of **The Legend of Zelda: Ocarina of Time** on Nintendo Switch 2, **November 5th, 2026**.

**Live site:** https://alextirgard00n.github.io/oot-countdown/

The follow-up to my [Tears of the Kingdom countdown](https://github.com/alextirgard00n/totk-countdown).

## Features

- Counts down to midnight on release day in your own time zone
- Each number pops when it changes
- Switches to "Out Now" on release day instead of going negative
- Desktop layout puts the key art beside the countdown; on phones the logo moves to the top so Link stays in view
- Open Graph and Twitter tags for link previews

## Built with

Plain HTML, CSS and JavaScript. No frameworks and no build step.

```
index.html
style.css
script.js
media/                           key art, logos, favicon, preview image
the-wild-breath-of-zelda-font/   display font
```

## Run it locally

Open `index.html` in a browser.
